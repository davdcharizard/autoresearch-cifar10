# Bag of Tricks for Image Classification with CNNs (He et al., CVPR 2019)

**Source**: He, Zhang, Zhang, Xie, Li — "Bag of Tricks for Image Classification with Convolutional Neural Networks" (CVPR 2019), arXiv:1812.01187

## Key Insights (the FREE, compute-neutral tricks relevant here)

- **Zero-init residual γ ("zero gamma")**: initialize the γ (scale) of the LAST BatchNorm in each residual block to 0, so each residual branch outputs 0 at init and the block starts as an identity map. Eases early optimization / signal propagation; reported small consistent top-1 gains on ResNet-50 (ImageNet). Compute- and param-neutral (γ is an existing BN parameter, just initialized differently).
- **No-bias-decay**: apply weight decay ONLY to conv/linear WEIGHTS, never to BN γ/β or to biases. Decaying the few BN/bias params is unnecessary and can slightly hurt; excluding them is standard best practice. Compute-neutral (just two optimizer param groups).
- Other tricks in the paper already in our recipe: cosine LR decay, label smoothing (0.1), large-batch LR scaling (tested EXP-025 — failed here), mixup (tested EXP-011/018 — failed here). ResNet-B (stride on the 3×3 not the 1×1) is ALREADY our main path. **ResNet-D** (avgpool-2 before a stride-1 1×1 SHORTCUT, so the lossy stride-2 1×1 no longer drops 3/4 of pixels) is NEAR-COMPUTE-NEUTRAL — it touches only the cheap 1×1 shortcut (1×1 FLOPs unchanged at the downsampled resolution + a trivial avgpool), UNLIKE BlurPool/EXP-024 which moved the heavy 3×3 main conv to stride-1 (4× FLOPs → epoch wall). ResNet-D is the fair compute-neutral re-test of EXP-024's masked anti-aliasing hypothesis (EXP-027). ResNet-C (3×3 stem stack) IS compute-adding — skip.
  - **EXP-027 RESULT — ResNet-D REGRESSED (fair test):** best_test_acc 95.75 (−0.47pp), final_test_loss WORSE 0.195→0.210, at a throughput-neutral 89 ep (dt ~8.7ms, params unchanged). So the avgpool-2 → stride-1 1×1 shortcut HURTS on this shallow 2-downsample CIFAR net — the lossy stride-2 1×1 is better (the avgpool low-pass blurs high-freq signal; the strided 1×1 is a learned subsample). ResNet-D's deep-ImageNet gain does NOT transfer to shallow CIFAR. Combined with EXP-024 BlurPool, the anti-aliased/information-preserving downsampling axis is CLOSED from both the expensive and compute-neutral sides. Do NOT retry downsample variants here.

## Relevance to this project (CIFAR-10 k=4 WRN, 300s/H20)

- The recipe is convergence-bound (not overfit-bound), so compute-NEUTRAL convergence-quality levers are exactly the right class — no epoch-wall risk (unlike compute-adding structural changes EXP-004/009/015/024). Zero-gamma + no-bias-decay are the two remaining untried free tricks.
- CAVEAT on magnitude: zero-gamma's benefit is largest for DEEP nets; ResNet-20 is shallow (9 residual blocks) so the gain may be small. WD is already only 1e-4, so no-bias-decay's effect is also small. Bundling both maximizes the chance of clearing the +0.1pp bar; noise floor here is ~0.2pp.
- **EXP-026 RESULT — within-noise NULL:** the bundle (zero-γ + no-bias-decay) gave best_test_acc 96.18 (−0.04pp vs 96.22), a fair compute-neutral 93-ep run (dt 8ms, params/VRAM unchanged). final_test_loss FELL 0.195→0.190 but top-1 did not move — the "polish moves loss not top-1" pattern (project-insights). Confirmed marginal: zero-γ needs depth (null on shallow ResNet-20 that already trains stably), and WD=1e-4 is too small for no-bias-decay to bite. Do NOT retry these for a top-1 goal at this budget.
- Implementation: zero-gamma = after `self.apply(self._weights_init)`, loop modules and `nn.init.zeros_(block.bn2.weight)` for each BasicBlock. No-bias-decay = split params into two SGD groups (weight_decay=1e-4 for ndim≥2 weights, 0 for ndim≤1 BN/bias params). Both train.py-only, no new deps.
