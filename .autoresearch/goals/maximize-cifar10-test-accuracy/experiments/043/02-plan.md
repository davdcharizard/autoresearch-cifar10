## Code Changes

- **`train.py` / exact helper**: define `centralize_convolution_gradients(parameters)` beside the other pure training helpers. Its complete body is the fixed loop: obtain `parameter.grad`; when non-`None`, run `gradient.sub_(gradient.mean(dim=(1, 2, 3), keepdim=True))`. It has no branch, option, state, logging, return-driven control, scale, or tensor discovery. Factoring this exact operation makes the production code directly invocable by the semantic and timing harness instead of testing a duplicated approximation.
- **`train.py` / `main()` model setup and post-backward path**: immediately after `WideResNet(...).to(device)`, create one ordinary Python list from `[module.weight for module in model.modules() if isinstance(module, nn.Conv2d)]`. It must contain all and only the 18 registered convolution weights in module traversal order, totaling 983,472 elements and 1,392 output filters. Immediately after the sole `loss.backward()` and before `optimizer.step()`, call the helper with that cache. The list adds no model/optimizer state or RNG use. The helper does not rescale the residual gradient and never touches BatchNorm, pooled-head, classifier, activation, decay-added, momentum-buffer, or Nesterov gradients.
- **`.autoresearch/.../experiments/043/preflight.py`**: required loop artifact under the globally gitignored `.autoresearch/` tree, not production experiment source. `.autoresearch/CLAUDE.md` requires per-phase artifacts, explicitly defines this tree as gitignored/local-only, and the repository has used the same ignored `preflight.py` convention in prior loops; the goal's production-modification constraint remains exactly `train.py` only. ## Configuration Changes

- Convolution data-gradient rule: ordinary autograd gradient -> per-output-filter zero-mean projection across `(C_in,K_h,K_w)` for every update from first through final.
- Selected scope: exactly 18 `Conv2d.weight` tensors / 983,472 values / 1,392 output-filter directions. All 2D linear matrices and all rank-one/bias tensors are excluded.
- Optimizer ordering: projection occurs before PyTorch SGD internally adds accepted coupled decay. For selected `W`, `C=P(G)`, `D=C+5e-4*W`, `B=D` if fresh else `B=0.9*B_prev+D`, and `W_next=W-lr*(D+0.9*B)`. Do not project `D`, the buffer, or the Nesterov direction.
- Everything else remains accepted: 1,003,482 parameters; `(2,2,3)` WRN; scale-0.1 bias-free `128->64->128` pooled head with isolated seed 36036; GAP and affine classifier; FP32; batch 256; global 0.2-to-0.002 cosine; continuous matrix `5e-4` coupled decay; momentum 0.9/Nesterov; batch-shared alpha-0.2 mixup and N1/M5 RandAugment through accepted 65% transitions; seed 42; loader; sole CE; evaluator; and 300-second budget.
