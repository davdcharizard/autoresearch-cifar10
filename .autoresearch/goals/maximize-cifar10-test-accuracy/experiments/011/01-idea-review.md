2. **`[2,2,3]` is materially distinct from `[32,64,160]`, although it tests the same broader low-resolution-capacity thesis.** EXP-010 expanded the 8x8 feature basis and changed the 64-to-stage projection, final BN, and classifier; this candidate retains the accepted 128-channel interface and instead adds two nonlinear transformations inside one new identity residual branch. The evidence remains indirect: EXP-010's +0.04 establishes only a directional low-resolution-capacity signal, and the WRN reference favors shallower/wider allocation in general. A valid negative result should close only this exact `[2,2,3]` topology, not all depth or all stage-3 capacity.
