# Report EXP-011: CutMix data-mixing regularization
- **Created**: 2026-06-29

## Goal
Maximize CIFAR-10 `best_test_acc` (%) within the fixed 300s training budget, editing only `train.py`. Baseline (EXP-008) = **96.38%**; bar = **≥96.48%** (+0.10pp) AND clearly above the ~0.1pp noise floor. Higher is better.

## Idea & Hypothesis
Add **CutMix** (Yun et al., arXiv:1905.04899) — paste an area-`(1-λ)` box from a batch permutation into each image and train on the area-split loss `λ·CE(out,y)+(1-λ)·CE(out,y_perm)`. Chosen by the cross-model brainstorm reviewer (8/7 over WD-shaping and SAM) as the finalist best aligned with the diagnosed limiter: the net is **regularization-bound with a ~4× epoch surplus**, and throughput-free regularization is the only >noise lever in this project's history (EXP-008 stronger aug, +0.38pp). CutMix is mechanistically *complementary* to the existing single-image occlusion aug (real cross-class content + soft labels vs zeroing a box) and — unlike mixup — pays off at short schedules (ResNet-18 CutMix ≈96.2 @200ep). **Hypothesis**: CutMix (α=1, p=0.5, tail-disabled in the final 15%) lifts `best_test_acc` above 96.48 while keeping `num_epochs` in the ~142–155 band, because region-mixing converts surplus epochs into a flatter, better-generalizing minimum.

## Approach
All edits in `train.py` (sole editable file). Added `import os`; a module-level `cutmix_batch(inputs, alpha)` helper drawing the box center / λ / apply-coin on **CPU** (the review-mandated fix to avoid a CUDA `.item()` sync inside the timed step) with an on-device permutation paste, returning the area-corrected `lam`; a training-step branch on a CPU apply-coin (disabled once `progress≥0.85`) computing the two-term mixed loss with the same `criterion` (so `label_smoothing` composes linearly with the area-mixed targets); a `cutmix_applied` counter; and self-describing config + realized-rate prints in the summary. `LABEL_SMOOTHING` and `CUTMIX_P` made env-overridable to run the review-mandated **2-cell LS-interaction decision** without editing the tracked file. num_params, architecture, optimizer, schedule, EMA, TTA all unchanged. Full plan: `02-plan.md` (hardened against a 12-point plan review: self-describing logs, unified throughput thresholds, thin-winner confirmation, log archival).

## Execution
Two full 300s runs on GPU 1 (free; foreign job on GPU 0), both clean, exit 0, ~26k img/s (no divergence, no throughput regression — the CPU draws are genuinely free). Milestone-1 smoke (50 draws) verified the helper. **cell-1** (CutMix @ LS 0.2 = baseline value, the clean single-variable test) → 96.40, but **ep25 91.21** vs EXP-008's ~92.31 (depressed ~1.1pp, below the pre-registered ~91.5 under-fit threshold) → the over-softening signature. This triggered the pre-registered **cell-2** (LABEL_SMOOTHING 0.1) → 96.32, ep25 91.65. The optional p=0.25 de-risk was **not run** (no path to the bar — see Results). Logs archived to `experiments/011/run_cell1_ls02.log`, `run_cell2_ls01.log`.

## Results
- **Primary metric**: best **96.40%** (cell-1, LS 0.2) — baseline 96.38, delta **+0.02pp** (+0.02%). cell-2 (LS 0.1) = 96.32 (−0.06pp). Both below the 96.48 bar, both within the ~0.1pp noise floor.
- **Observations**: CutMix was genuinely applied (cell-1 41.8%, cell-2 41.6% of steps ≈ the expected ~42% at p=0.5 with tail-disable). Both runs fully annealed (peaked-then-dipped: cell-1 best 96.40 @ep133→96.27 @ep142; cell-2 96.32 @ep133→96.21 @ep143) at clean epoch counts (142/143 ≥142), so this is NOT under-anneal — it is a genuine ceiling. CutMix **depressed early convergence** in both cells (ep25 91.21/91.65 vs 92.31) — the harder mixed task. Lowering LS 0.2→0.1 lifted ep25 only +0.44pp and **lowered** the final ceiling (96.32 < 96.40), so the annealed optimum is insensitive to LS in this range.
- **Analysis**: The hypothesis is **falsified**. The "stability/throughput-free" half held (no divergence, num_epochs normal, ~26k img/s), but the "better-minimum" half did not: CutMix only **matches** the EXP-008 baseline (96.40 vs 96.38, a tie within noise), it does not clear the bar. The over-softening sub-hypothesis (CutMix soft labels + LS 0.2 over-regularize) was tested and **rejected** as the limiter — reducing LS did not recover; the ceiling is unchanged regardless of LS. The mechanism evidence (early-convergence deficit + unchanged annealed ceiling) points to CutMix being **redundant with the existing strong occlusion aug (Cutout12 + RandomErasing)** on this saturated base: region-mixing re-regularizes a net that is already near its regularization-limited generalization ceiling, adding training difficulty without shifting the fully-annealed optimum. This matches the pre-registered null read: "both cells in [96.30,96.45] at normal epochs → CutMix redundant on the saturated base."
- **Key Learning**: A *second*, mechanistically-distinct strong augmentation (CutMix on top of Cutout+RandomErasing) does NOT stack — it only matches the baseline (96.40 vs 96.38) — i.e. the augmentation/regularization axis is approaching saturation on this net at 300s, not just the optimizer axis.

## Unexplored Avenues
- **CutMix as a REPLACEMENT for (not addition to) the occlusion aug**: this experiment stacked CutMix on top of Cutout12+RandomErasing. If they are redundant, swapping Cutout/RE *out* for CutMix (rather than adding) might find a better single-regularizer operating point. Low-medium confidence — likely still ~baseline given the saturation signal, but it tests the redundancy hypothesis directly.
- **mixup / manifold-mixup**: rejected for short schedules (needs 800+ ep); not worth trying at this budget.
- **CutMix at higher p with a longer/​hotter schedule co-tune**: the early-convergence deficit suggests CutMix wants more epochs; but capacity-for-epochs trades under-anneal here, so this is low confidence.
- **The augmentation axis now shows saturation evidence** (EXP-008 was the *first* strong aug and won +0.38; CutMix as the *second* ties) — future regularization should target a *different* mechanism (weight-space or target-space), not more input-space aug.
