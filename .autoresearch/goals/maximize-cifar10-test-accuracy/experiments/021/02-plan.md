# Plan EXP-021: Compile-funded DEPTH at the 8×8 stage (second ReZero GatedResidual at layer2)

- **Created**: 2026-06-30

## Summary of the test
Add ONE identity-initialized ReZero `GatedResidual(256)` to `layer2` (the proven 8×8/256 stage), and fund its per-step cost with the EXP-014-validated, math-equivalent torch.compile +12% throughput so the deeper net still anneals (`num_epochs ≥ 135`). Verdict-bearing comparison isolates DEPTH: both control and treatment are compiled + off-budget-warmed; only the extra block differs. Baseline 96.38; bar = cA ≥ 96.48 AND cA − c0 > 0.1pp, replicated on a confirmation pair.

## Code Changes
- **train.py** (ONLY editable file):
  - **Env knobs + imports**: `import os`; `USE_COMPILE/DEPTH/WARMUP/COMPILE_MODE` env reads. Rationale: keep the default bare run byte-identical to baseline (reviewable diff; clean control); env-select the cells.
  - **`ResNet9` depth**: append one `GatedResidual(256)` to `layer2` when `extra_depth`. Rationale: directly extends EXP-004 (the only architectural win — first GatedResidual@layer2, +0.13pp) by asking "does a second help?"; ReZero α=0 → identity at init (deeper net starts bit-equivalent to proven net, no cold-start regression). Edge case: `_weights_init` only touches Conv2d/Linear weights, NOT the bare `alpha` Parameter → α=0 preserved (no SE-style clobber). Whitening load is post-init and untouched.
  - **`ResNet9` RNG-isolated init** (plan-review #1, the main blocker): the extra block must NOT perturb the RNG draws of the shared layer3/fc nor the training data stream. Replace the blanket `self.apply(self._weights_init)` with: init all SHARED leaves via `for m in self.modules(): if id(m) not in extra_ids: self._weights_init(m)`, then init `self.layer2[3]` under `torch.random.fork_rng(devices=[])`. For `DEPTH=0`, `extra_ids` is empty so the loop reproduces the original init order exactly (byte-identical baseline). This guarantees the cA−c0 comparison isolates DEPTH alone (shared weights + shuffle/aug stream identical; only the identity block differs). Risk: getting the leaf order wrong → smoke check (b) bit-equality of shared params + post-init RNG draw catches it.
  - **torch.compile wrapper** (reuse EXP-014-validated recipe, knowledge/references/torch-compile-throughput.md): separate `train_fwd` handle, uncompiled `model`/EMA/eval, off-budget warmup with BN snapshot/restore + local-RNG dummies + no optimizer.step. Rationale: funds the depth block's per-step cost off-budget so `num_epochs ≥ 135` (the #1 failure mode is under-anneal: EXP-005/007). `mode="default"` (cudagraphs/reduce-overhead conflict with fresh per-step dataloader tensors + EMA). Risk: recompile leak / BN pollution → caught by the smoke (aliasing, BN round-trip) and the in-run first-step dt + num_epochs check.

## Abort Criteria
- **GPU-1 contention** (infra-errors EXP-010/014, the dominant confound): before/during each cell, if `nvidia-smi` shows a FOREIGN high-util process on GPU 1, OR a cell's steady `img/s` falls > ~15% below its clean band (compiled no-depth ~27–30k; compiled depth expected ~24–26k), OR `num_epochs` lands far below the clean band → DISCARD the session and re-run the FULL pair once GPU 1 is idle (same-session controls only hold if BOTH cells were equally uncontended). Pre-registered numeric tripwire: steady img/s < 22000 on EITHER cell, OR a foreign GPU-1 PID with >2 GB AND >50% util in the sampler.
- **Under-anneal of cA**: if `num_steps(cA) < 13095` (≈135 epochs-equiv; num_steps used because `epoch` increments before the batch loop so num_epochs overcounts the final partial epoch, plan-review #4) despite compile → cA is under-annealed; its accuracy is NOT a fair depth verdict. The Milestone-2 sizing gate should prevent this; if it still happens, the run is INCONCLUSIVE (not "depth closed") and EXP-021 aborts to analysis as infeasible-at-budget. Do NOT substitute a single-conv variant.
- **Inconclusive-null guard**: a cA null only CLOSES the depth axis if cA was properly annealed — `num_steps ≥ ~14065` (≈145 ep) AND tail annealed (best within ~0.05pp of final, not still-rising). A null at fewer steps / still-rising tail is inconclusive (depth may help but couldn't anneal), recorded as such, not as evidence depth is exhausted.
- **Divergence / crash**: NaN/inf in loss, OOM, or no log output after ~2 min → kill, inspect `tail -50 run_<cell>.log`, categorize (infra vs code) per the execute skill.
- **Compile leak**: if the first ~10 in-loop steps on a compiled cell stay >2× the steady dt (in-loop recompile), warmup failed → fix the warmup shape/mode before trusting the run.

## Verification Protocol

### Verification Procedure
Baseline from `exp-index.sh baseline` = **96.38** (commit 07c3760). Verdict keyed on cA (the compiled depth cell). Evaluate conditions in order; first failure ⇒ no-improvement.

1. **NC1 — completion & budget** (per cell): `grep "^best_test_acc:\|^training_seconds:\|^total_seconds:" /tmp/exp021_run_<cell>.log` shows a valid `best_test_acc`, `training_seconds ≈ 300.0`, `total_seconds < 600`; `grep -ic 'nan\|inf' /tmp/exp021_run_<cell>.log` = 0. Fail ⇒ crash.
2. **NC3 — integrity** (process): `git status --porcelain` shows only ` M train.py` (run logs live in /tmp, autoresearch artifacts under gitignored `.autoresearch/`); `git diff --quiet -- prepare.py` (eval harness byte-unchanged); `manual_seed(42)`/`cuda.manual_seed(42)` intact (warmup + extra-block init use LOCAL/forked generators); exactly one `evaluator.evaluate` per epoch; per-epoch `best:` max == reported `best_test_acc` (no eval-cache/seed anomaly); `num_steps(cA) ≥ 13095` (≈135-ep anneal floor; the gain, if any, is annealed not a throughput artifact). Any fail ⇒ invalid.
3. **NC2 — improvement gate** (verdict): require `best_test_acc(cA) ≥ 96.48` (baseline+0.1) AND `cA − c0 > 0.1pp` (same-session control, beyond the noise floor). If BOTH hold → trigger the confirmation pair in REVERSED order `{cAb then c0b}` and require `cAb ≥ 96.48` AND `cAb − c0b > 0.1pp` (delta REPLICATES — mandatory; the low-control-draw artifact recurred 4× in EXP-016/017/019/020). Only a replicated, floor-clearing, control-beating delta = `improvement`; else `no-improvement`.
4. **Contention guard** (gates trust in NC2): confirm via `/tmp/exp021_smi*.log` that BOTH cells ran uncontended (no foreign GPU-1 PID; img/s in band; epochs comparable). If unequal contention → discard & re-run before rendering any verdict.
