## Resolutions (folded into 02-plan.md)

1. **AUG_MODE default runs baseline** → On a WIN, the winning mode is baked as the train.py DEFAULT and the bare `uv run train.py` is re-confirmed before commit (M4 + Verification step 7). For the experiment itself, cells are explicitly env-gated; baseline-default is the regression guard.
2. **Pass without beating recorded baseline** → Primary necessary condition is now the ABSOLUTE bar best ≥ 96.48 (baseline 96.38 + 0.1pp); same-session c0 is the noise control, not a substitute (Hypothesis, M4, Verification 5b).
3. **Best-of-two multiple comparison** → Added explicit multiple-comparison caveat: a hairline max(cA,cB) pass uncorroborated by the other policy cell is treated as unproven (M4, Verification 5b).
4. **Off-budget CPU aug inflates wall** → Pre-smoke probe uses the HEAVIEST cell (randaug_add); total_seconds is a verdict metric with a <600s guard + fairness note (M2, Verification 6).
5. **smoke_throughput.py violates train.py-only scope** → Probe is now an INLINE `uv run python -c` (no file created); calls `train.build_train_tf` (M2).
6. **`import train` doesn't build train_tf** → Added module-level `build_train_tf(mode,n,m)`; smoke calls it for all 3 modes (M1, Code Changes).
7. **Replacement overclaims negative evidence** → Added randaug_add cell (policy ADDED on top) to disambiguate over-regularization vs unhelpful mechanism; hypothesis's negative-inference guard now scopes the claim to "increment over current occlusion recipe" only (Hypothesis, M3, Config).
8. **Under-fit check incomplete** → Verdict now extracts final_test_acc + late-epoch trend (best-vs-final) alongside ep25 (M4, Verification 4).
