## Prioritized Constructive Feedback

**1. [GC retry] The biggest hole is effect *magnitude*, not correctness — and the idea leans on sunk cost.** The knowledge file (`knowledge/papers/gradient-centralization.md`) records ordering and mechanism but **zero quantitative CIFAR numbers**, while `02-system-understanding.md` says a credible child needs a stable ~0.25–0.30-point effect (selection noise alone spans ~0.17). GC's published CIFAR gains on BN-equipped networks are typically small, and this recipe already stacks CutMix + drop path + cosine LR, which compresses optimizer-conditioning headroom further. Much of the "Reasoning" section is procedural ("we already proved the math, EXP018 validated the harness") — that lowers cost, it is not evidence of effect size. *Fix:* before planning, pull the paper's actual WRN/CIFAR deltas into the knowledge file and state the expected magnitude honestly; preregister that a complete valid run below 95.33% is definitive negative evidence for this composition (the draft already does this — keep it binding), and frame the run partly as cheap resolution of an open question.

**2. [GC retry] Per-step launch overhead is unlike anything EXP-018 validated.** EXP-018's foreach work was cadence-5 *sparse*; GC runs 17 row-mean reductions + subtractions **every step** on a ~10 ms step, and EXP-009 showed small-kernel accumulation killing a candidate at 20.7% overhead before accuracy was ever measured. The risk note names this but proposes no mitigation. *Fix:* implement as one fused foreach mean + one foreach broadcast-subtract (no per-tensor Python loop), and gate on a parent-relative paired-latency preflight with a dispersion ceiling calibrated per the EXP-016 learning (`03-experiment-learnings.md` § Protocol Findings) — not another ad-hoc absolute gate (EXP-008 lesson).

**3. [GC retry] The failure mode to design against is the harness, which has now killed two nodes.** EXP-016 died on an uncalibrated dispersion gate and EXP-017 on retained diagnostic scalars — neither on science. The summary says "rebuild the accuracy-blind harness around EXP018's validated pattern"; make that literal: reuse EXP-018's preflight structure verbatim (scalar-only finiteness accumulation, post-persistent-state allocation baseline, fixed diagnostics), adding only the GC op. Any novel assertion is new crash surface.

**4. [Companion head] Near-fatal architecture mismatch, admitted in its own text.** Deeply-Supervised Nets (2015) motivates companion heads by gradient starvation in deep *pre-residual, pre-BN* plain nets; this is a 16-layer PreAct residual network with BN, and the brainstorm concedes it "is not known to be gradient-starved." Worse, training the head on **CutMix area-weighted targets at a pooled mid-level feature** is novel, unvalidated semantics — DSN used clean targets, and area-proportional label weight has no reason to hold at block-4's pooled representation. The fixed "modest coefficient" and attachment point are uncalibrated one-shot guesses in a regime where EXP-003 showed sub-0.3-point scalar choices don't survive confirmation. *Fix if pursued:* route through the sweep path for coefficient (and clean-target-on-clean-batches variant), and produce any evidence that this network's block-4 features are under-discriminative before spending the run.

**5. [Mixup hybrid] Partially retries EXP-003's failed direction and overstates its source.** Converting clean early batches to Mixup raises the total mixed-batch fraction — the same axis EXP-003 pushed (CutMix 0.5→0.65) and saw reverse on confirmation (−0.29/−0.14). The cited NeurIPS 2022 note itself says the Mixup/CutMix choice "should be empirical rather than assumed universal," and that paper's hybrids (HMix/GMix-style) are *integrated* mixing operators, not additive stacking of both — so "analysis predicts complementary behavior" is a stronger claim than the source supports. Two new hyperparameters (gate, alpha) chosen blind sit exactly in the sub-0.30-point unresolved band (`03-experiment-learnings.md`). *Fix if pursued:* go through the sweep route with a small grid (e.g., alpha ∈ {0.1, 0.2}, gate ∈ {0.1, 0.2}) and require a confirmation margin per the EXP-003 lesson.

**6. [Cross-cutting] All three attack base 002, but the goal-level limiter is EXP-011's 95.49% stable EMA plateau.** Navigation already fixed the base, so this isn't a flaw in the candidates — but the winner should preregister what would justify later composition onto the 011 tip (per EXP-017's own note that one-seed gains are noise-limited evidence), so a local pass doesn't get over-read.

No candidate violates a hard constraint. The GC retry is **not** an illegal repeat: EXP-017's verdict was `crash` with an explicit "not negative GC evidence" finding, and both the 017 and 018 analyses recommend exactly this retry with a corrected harness — it is procedurally new.
