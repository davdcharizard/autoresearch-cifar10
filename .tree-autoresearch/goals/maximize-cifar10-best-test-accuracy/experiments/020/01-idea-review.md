# Adversarial Review — EXP-020 Brainstorm (three GC candidates)

## Prioritized Feedback

1. **[All / fatal-adjacent for the hypothesis framing] The classifier-attribution story ignores the energy arithmetic.** The classifier is ~2,560 of 2,745,264 eligible elements; even at 93.21% removed *norm ratio*, its absolute share of EXP019's 6.4162 removed squared-energy units is necessarily tiny — virtually all removed energy was convolutional (41.89% conv norm removal over ~2.74M elements). If GC's harm scales with removed energy, conv-only GC should reproduce nearly all of EXP019's −0.16. The conv-only case therefore rests on an unstated stronger claim: that small-norm distortion at the *output layer specifically* is disproportionately harmful to class boundaries. That claim is plausible but never articulated or quantified. Fix: compute the classifier's *absolute* removed-energy share from EXP019's existing 55 audits before running, and state the per-layer-sensitivity hypothesis explicitly in the plan, so a miss is interpretable.

2. **[All] The literature evidence does not transfer, and the brainstorm underweights the one in-domain datapoint.** The paper's +0.75 to +1.95 gains are CIFAR-100 SGDM at 76–79% baselines with conventional epochs; the only test in *this* regime (saturated 95%+ CutMix/drop-path wall-clock recipe) is EXP019, which hurt. Together with EXP018 (Lookahead also lowered the stable tail), the local pattern is "optimizer-side perturbations to this tuned recipe hurt." All three candidates should be honestly framed as cheap close-out ablations with modest upside (~+0.1–0.2 realistic, not paper-scale), whose main value is decisively closing the GC family. That is legitimate — but the eventual hypothesis should not promise paper-magnitude gains.

3. **[Raw-gradient] Unverified load-bearing assumption: that the L2 common-mode component is material.** The L2 contribution to a row mean is `wd × row-mean(weights)` with `wd = 1e-4`. If that is small relative to the data-gradient row mean — likely, and directly checkable — then raw-gradient GC is numerically almost identical to official-order conv-only GC and the run is a wasted near-duplicate. EXP019's audit infrastructure could have decomposed removed row-means into data-gradient vs L2 parts but didn't. Fix: do not spend a run on this; instead add a data-grad-vs-L2 row-mean decomposition audit to whichever candidate runs, answering this question for free. The brainstorm's own risk note (two simultaneous changes, weaker literature support) is correct and effectively self-disqualifying as the *first* follow-up.

4. **[Early-phase] Sequencing error and a double delta.** This candidate changes both eligibility (conv-only) and phase (first 75% only) relative to EXP019, so any outcome is unattributable — and it admits there is no phase-resolved energy evidence. It is the right *second* experiment if conv-only full-run GC fails: conv-only first isolates eligibility; phase-limiting then isolates timing. Running it now inverts the ablation order. Fix: have the conv-only run log removed energy *per phase* (CutMix / early-clean / late-clean buckets, cadence already exists), so the phase-limited variant becomes evidence-based or gets killed without a run.

5. **[Conv-only] The "decisive negative" claim needs preregistered closure criteria.** The idea's strongest selling point is that a valid miss "closes the remaining literature-supported GC rule." Make that real: preregister that a result ≤95.23% closes the GC family on this base entirely (including raw-gradient and phase-limited variants, given the audits from points 3–4), so a miss cannot spawn a third GC run on residual ambiguity.

6. **[Strategic, all] Ceiling note.** Even a success advances EXP002 (95.23%) to ~95.4%, still below the global best 95.61% and its 95.49% stable plateau. The navigation call to isolate GC on EXP002 is defensible, but the brainstorm should acknowledge that GC's only path to goal-level relevance is later transfer onto the EXP011 stack — which EXP019's SAM/EMA-free design conveniently keeps clean.

## Scored Verdict (evidence & reasoning / impact, 1–10)

**Convolution-only official-order GC** — Evidence **7**: narrowest single-variable follow-up to a complete negative, direct paper support ("conv-only sufficient for small-resolution CIFAR"), retains the full audit harness; docked for the unexamined energy arithmetic in point 1. Impact **5**: modest realistic gain, but highest information value — with the point-3/4 audits added it answers all three candidates' questions in one run.

**Early-phase convolution-only GC** — Evidence **4**: phase diagnosis is admittedly indirect, two deltas from EXP019 make any outcome ambiguous, and it weakens dose. Impact **4**: same modest ceiling with a worse shot at attribution; correct as a sequel, not an opener.

**Raw-gradient convolution-only GC** — Evidence **3**: hinges on an unmeasured assumption (L2 common-mode materiality at wd=1e-4) that plausibly makes it a near-duplicate of conv-only; weakest literature grounding; confounded double change by its own admission. Impact **4**: upside no larger than conv-only, and a negative generalizes poorly.

**Pick: Convolution-only official-order gradient centralization.** It is the only candidate that isolates exactly one variable against EXP019's complete negative, it carries the only direct literature support among the three, and — refined per the feedback — it should (a) report the classifier's absolute removed-energy share from EXP019 and state the output-layer-sensitivity hypothesis explicitly, (b) add per-phase and data-grad-vs-L2 removed-energy audits so the other two candidates are resolved without runs, and (c) preregister that a valid ≤95.23% result closes the GC family on this base. The other two are not independent bets; they are sub-questions this run can answer as instrumentation.
